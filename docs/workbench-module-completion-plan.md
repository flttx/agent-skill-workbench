# 工作台全模块闭环计划（现状盘点）

> 本文记录现有原型的功能差距，不是最终导航方案。目标信息架构和全面改版路线以 [`design/workbench-redesign.md`](./design/workbench-redesign.md) 为准。

## 结论

当前最完整的是“任务 → Agent → 结果”链路。工作区、文件收集、收件箱和 Skill 库已经有页面及部分 Rust/SQLite 能力，但还没有形成稳定的“采集 → 整理 → 关联项目/任务 → 执行”的工作台闭环。

因此，下一阶段不应只做 Agent 手工验收，而应先完成工作台基础模块，再进行全链路验收。

## 当前模块盘点

| 模块 | 当前状态 | 判断 |
|---|---|---|
| 今日行动 / 任务 | 创建、编辑、状态、项目关联、Agent Run、结果回填 | 核心链路已实现，待综合验收 |
| 工作区 / 项目 | 工作区 CRUD、目录绑定、概览、来源目录和活动视图 | 基础能力已有，项目上下文闭环不足 |
| 文件收集 / 来源 | 本地目录添加、扫描、文件索引、来源详情 | 本地扫描可用，采集入口和来源处理不足 |
| 收件箱 | 待处理列表、搜索、归档、忽略、项目/标签/Skill 归类 | 基础整理可用，缺少快速捕获和转任务闭环 |
| Skill 库 | 扫描、分组、版本、使用卡片、更新/复制 | 管理能力已有，推荐和草稿审核不足 |
| Agent 执行 | Codex/Claude/Cursor 启动、Prompt、历史、结果和基线差异 | 代码已实现，待真实场景验收 |
| 全局搜索 / 导航 | 命令面板和局部搜索 | 尚未覆盖任务、来源、文件、Skill 的统一搜索 |

## 阶段 6A：工作区与项目上下文

- [ ] 工作区列表、创建、绑定目录、切换和删除行为稳定。
- [ ] 项目详情能查看项目目录、来源、收件箱、知识条目、关联任务和最近 Agent 运行。
- [ ] 项目目录变更后，来源扫描和 Cursor 启动使用同一规范化路径。
- [ ] 一个任务可以关联多个项目，并能明确选择默认执行项目。
- [ ] 项目上下文可以预览、折叠和编辑，不把无关目录内容全部注入 Prompt。

## 阶段 6B：文件收集与来源处理

第一版优先保证本地和手动来源可用，不依赖外部 OAuth：

- [ ] 支持从工作台快速保存文本、想法和 Markdown 内容。
- [ ] 支持粘贴网页 URL、GitHub Issue/PR URL，并保留来源链接、标题和备注。
- [ ] 支持选择本地文件或目录作为来源，扫描失败时显示原因。
- [ ] 记录来源类型、来源路径/URL、所属项目、摘要、更新时间和可用状态。
- [ ] 增量扫描不重复创建同一来源，不因文件暂时不可用而丢失历史记录。
- [ ] 文件详情支持打开原文件、查看摘要、关联项目、关联任务和关联 Skill。

## 阶段 6C：收件箱处理闭环

- [ ] 新捕获内容默认进入收件箱，不自动污染项目知识库。
- [ ] 收件箱支持搜索、筛选、批量或逐条归档、忽略和重新打开。
- [ ] 一条来源可以直接生成任务草稿，自动带入来源、摘要和项目候选。
- [ ] 一条来源可以关联已有任务，不重复创建任务。
- [ ] 收件箱页面显示“待处理原因”和下一步动作，而不是只有文件列表。
- [ ] 处理完成后能追溯来源 → 任务 → Agent Run → 结果。

## 阶段 6D：Skill 库与推荐

- [ ] 保留当前 Skill 扫描、分组、版本和可用性状态。
- [ ] 根据任务标题、目标、来源和项目背景推荐已有 Skill。
- [ ] 识别“值得沉淀为 Skill”的执行方法，生成可编辑草稿。
- [ ] Skill 草稿必须经过用户审核后才能保存或复制到 Agent 目录。
- [ ] 任务详情能查看推荐原因和已关联 Skill，不要求用户手填 Skill ID。

## 阶段 6E：今日行动与统一入口

- [ ] 今日行动除了任务，还显示待处理收件箱和需要确认的执行结果。
- [ ] 首页每个卡片都有明确下一步：整理来源、确认任务、启动 Agent、保存结果或关闭任务。
- [ ] 快速捕获支持键盘操作，并能在不离开当前页面的情况下生成来源或任务。
- [ ] 全局搜索覆盖任务、项目、来源、文件和 Skill，并显示对象类型。
- [ ] 应用重启后保持当前工作区、收件箱状态、任务和 Agent Run 记录。

## 阶段 6F：Agent 子计划

Agent 启动、历史回填和最终改动文件差异继续按 [`phase-6-acceptance-plan.md`](./phase-6-acceptance-plan.md) 验收，但必须放在工作区、来源和收件箱闭环之后执行：

- [ ] Agent Prompt 使用选定项目和来源生成。
- [ ] Agent Run 能回链到任务和项目。
- [ ] 结果中的最终改动文件、验证结果和未解决问题可回到任务详情。
- [ ] 任务不会因为 Agent 运行结果自动完成。

## 优先级

1. **P0**：工作区目录、来源、收件箱、任务之间的关联和数据不丢失。
2. **P1**：文本/URL/GitHub/本地文件快速捕获，来源转任务和全局搜索。
3. **P1**：Skill 推荐、草稿审核和任务上下文预览。
4. **P2**：批量处理、外部平台深度同步、导出和视觉细节。

## 阶段退出条件

用户可以完成以下闭环：

```text
看到网页 / GitHub / AI 对话 / 本地文件
→ 快速保存到收件箱
→ 整理并关联项目
→ 转为任务或关联已有任务
→ 预览上下文并选择 Agent / Skill
→ 执行并回填结果
→ 在今日行动中继续或关闭
```

只有 P0 闭环通过、P1 核心入口可用，并完成 Agent 子计划的真实验收，阶段 6 才能标记完成。

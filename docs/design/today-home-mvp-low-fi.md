# 今日首页 MVP 低保真交互稿

> 版本：0.1 · 日期：2026-09-22  
> 状态：已实现，待真实 Tauri 窗口验收  
> 范围：个人工作台首版 P0，仅覆盖“今日首页”和项目进度草稿

## 1. 设计目标

用户每天打开工作台后，在 30 秒内完成以下动作：

1. 看到默认项目和数据可用性。
2. 确认 Codex 与 Git 均可用。
3. 生成确定性项目进度草稿。
4. 编辑并保存一个新的工作台进度版本。

首版不包含周报、周看板、完整 Skill 网格、自动写回项目文档或 AI 生成内容。

## 3. 项目选择规则

- 存在置顶项目时，按置顶顺序选择主项目。
- 没有置顶项目时，选择最近活跃项目。
- 主项目不可用时不自动替换，保留项目卡片并显示不可用原因。
- 点击其他项目只切换当前上下文，不直接生成草稿。

## 4. 生成进度草稿

点击“生成进度草稿”后执行只读流程：

```text
检查 Codex → 检查 Git → 读取配置的进度文档
→ 汇总确定性证据 → 展示草稿预览
```

约束：

- Codex 与 Git 必须同时可用，否则按钮禁用，首页保持只读。
- 最长等待 10 秒，超时后保留缓存并显示失败原因。
- 不调用 AI，不执行项目脚本，不修改项目文件，不执行 Git 写操作。
- 生成过程中按钮显示“生成中”，并设置 `aria-busy="true"`。

## 5. 草稿预览与保存

草稿在右侧抽屉或页面内展开面板中预览，不使用无法回溯上下文的确认弹窗。

字段顺序：

1. 当前阶段
2. 上次完成
3. 下一步
4. 阻塞
5. 验证状态
6. 工作区变化
7. 来源与更新时间

证据规则：

- 证据优先级为 Git / 明确验证记录 > 项目进度文档 > Codex 摘要。
- 没有证据的字段显示“未记录”，不得自动猜测。
- 每个结论都可展开查看来源。
- 用户修改字段后标记为“已确认”。

保存行为：

- 主按钮文案为“保存为新版本”。
- 每次保存生成不可变版本，并更新项目当前进度指针。
- 历史版本可查看，不覆盖旧版本。
- 后续自动生成只更新未确认字段。
- 新证据与已确认字段冲突时显示冲突提示，由用户决定是否更新。

## 6. 状态矩阵

| 状态 | 视觉与文案 | 可执行动作 |
|---|---|---|
| 正常 | Codex、Git 均可用；证据完整 | 生成进度草稿 |
| 数据过期 | 黄色提示最后刷新时间 | 查看状态；数据恢复后再生成 |
| Codex 不可用 | 明确显示不可用原因 | 只读 |
| Git 不可用 | 明确显示不可用原因 | 只读 |
| 项目目录不存在 | 红色阻塞状态与路径 | 查看详情 |
| 生成中 | 显示进度并禁用重复点击 | 等待或取消 |
| 生成失败 | 保留旧版本和失败原因 | 重试 |
| 保存成功 | 显示新版本号和保存时间 | 查看版本 |

## 7. 空状态与降级

- 没有项目：引导扫描或手动添加项目目录。
- 没有可用 Codex/Git：显示缓存首页，并说明当前只能查看。
- 没有历史版本：显示“尚未保存进度版本”，保留生成入口。
- 单个项目不可用：只影响该项目卡片，不阻塞其他项目展示。
- Codex 数据库锁定：首页不白屏，继续展示最后一次缓存。

## 8. 响应式与可访问性

- `760px` 以下由双栏改为单列。
- 主操作在窄屏首屏仍保持可见。
- 所有图标按钮提供 `aria-label`。
- 生成按钮使用 `aria-busy` 表达异步状态。
- 状态同时使用文字、图标和结构提示，不只依赖颜色。
- 抽屉打开时聚焦第一个可编辑字段，关闭后返回触发按钮。
- 遵守 `prefers-reduced-motion`，动效不承担业务信息。

## 9. 低保真验收条件

- 首屏只存在一个最高强调动作：生成进度草稿。
- 默认项目遵循置顶顺序或最近活跃兜底规则。
- 项目不可用时不会被静默替换。
- Codex 或 Git 不可用时无法生成或保存新草稿。
- 生成超时上限为 10 秒，失败后仍可查看缓存。
- 草稿字段、来源、更新时间和可信度均可辨识。
- 保存后能看到新版本，旧版本仍可查看。
- 用户确认字段不会被后续生成静默覆盖。
- 760px 以下无横向溢出，键盘焦点和错误反馈可见。

## 10. P0 缺口补齐（2026-10-08）

- 项目卡片增加折叠的进度文档配置，使用项目内相对路径，最多 8 份可读 Markdown；空配置自动发现根目录 `PROGRESS.md`、`docs/development-progress.md`、`task_plan.md`、`findings.md`，按顺序聚合。拒绝绝对路径、上级目录、外部符号链接和不可读文件；原文保持只读。
- 文档解析识别明确字段与章节，支持中文冒号和下一步章节的首个列表项；无法读取的候选作为不可用来源展示。
- 生成后数据源失效时，保存必须被后端拒绝，已有版本和项目指针不变。前端刷新为不可用后，草稿编辑及保存禁用；恢复后继续编辑。
- 已确认字段的新证据冲突显示旧值与新值，用户可保留、采用或手工编辑。未处理冲突不能保存；无证据默认值不构成冲突。
- 搜索覆盖项目名称、路径与 Skill，项目结果切换今日页主项目；切换项目后忽略旧项目迟到的草稿和历史结果。
- 保存文档配置不会删除当前编辑，当前草稿仍保留生成时的来源；重新生成才使用新配置。
- 自动验证覆盖 Rust 业务规则与使用模拟 IPC 的浏览器交互；真实 Tauri 窗口、冷启动性能、安装升级和窄屏首屏主操作仍需单独验收。

## 11. 保留星空的界面优化（2026-10-08）

- 用户确认保留星空并降低内容区干扰；今日页内容改为稳定深色底，使用单一页面标题，取消重复生成卡片，置顶与同步降为辅助动作。
- 项目名旁直接切换，摘要允许两行；生成后“重新生成草稿”为次操作、保存为主操作。Git状态就地展开，区分查看已读状态和刷新。
- 窄屏侧栏改为横排导航。四主题在1180×760、900×600、760×900、390×844、320×844合成数据场景验证主项目、数据源和主按钮首屏可见；390px按钮约691–731px，原评估约1380–1420px。
- 该布局修复通过浏览器检查，但真实Tauri、长项目名/多行摘要、系统缩放和安装升级继续单独验收。

## 12. 首次使用入口补齐（2026-10-08）

- 没有项目时直接提供“添加项目”；已有项目时可从今日工具区继续添加。
- 弹窗复用项目保存命令和主题控件，填写名称、选择或粘贴目录；打开聚焦名称、取消回到触发按钮，失败保留输入，保存中阻止重复操作。
- 成功进入今日页新项目，随后可生成、编辑并保存第一个进度版本；保存成功而刷新失败时明确已保存并引导刷新，避免重复创建。
- 浏览器合成IPC已验证空首页→添加→生成→编辑→保存v1，以及取消、目录选择失败、重复提交与刷新恢复。原生脚本同步从表单创建项目；真实CDP连接受限，原生首次链路尚未运行。
